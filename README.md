# The Ghost Inventory

> Thousands of items existed in the system but never on a single shelf. I chased the phantoms until the warehouse finally matched reality.

The question: Why did the reorder system keep buying stock that never reached a shelf?
The result: About 9,400 ghost SKUs quietly triggering reorders, and the cash they were draining.

## Run
    pip install -r requirements.txt
    python main.py

## Stack
SQL, Python, Power BI (this demo reconciles three simulated systems in pandas).
